# 🎓 Тесты

**Тесты** — браузерный сайт с проверочными тестами по языкам, литературе, математике, физике, естественным и гуманитарным наукам, религиоведению, экономике, регионоведению и альтернативным вселенным.

- **81 тест**.
- **50 вопросов в каждом тесте** — всего **4050 вопросов**.
- Четыре варианта ответа на вопрос.
- Интерфейс на русском языке.
- Не требует сборки или установки зависимостей.

## Возможности

- Разделы и подкатегории для удобного выбора теста.
- Случайный порядок вопросов и вариантов ответа.
- Возможность пропускать вопросы и возвращаться к ним во время прохождения.
- Итоговая оценка и разбор ответов после завершения теста.
- Учёт времени прохождения.
- Сохранение лучшего результата в браузере.
- Профиль пользователя для просмотра результатов по имени.
- Три темы оформления: светлая, бежевая и тёмная.
- Адаптация интерфейса для телефонов, планшетов и компьютеров.
- Возможность поделиться результатом.
- Необязательная облачная синхронизация результатов. В текущей конфигурации облачное хранилище не подключено: без настройки параметров сайт использует локальный кэш.

## Как пользоваться

1. Откройте сайт.
2. Выберите раздел и нужный тест.
3. Отвечайте на вопросы. При необходимости пропускайте вопрос и возвращайтесь к нему позже.
4. Завершите тест, чтобы увидеть результат и разбор ответов.
5. При желании задайте имя профиля для организации истории результатов на этом устройстве.

## Публикация через GitHub Pages

1. Загрузите все файлы проекта в корневую папку GitHub-репозитория.
2. Откройте в репозитории **Settings → Pages**.
3. В разделе сборки выберите публикацию из ветки (**Deploy from a branch**), затем нужную ветку (например, `main`) и папку `/ (root)`.
4. Сохраните настройки и дождитесь завершения публикации.
5. Откройте URL, который покажет GitHub Pages.

Файлы `index.html`, `style.css`, `questions.js`, `cloud.js` и `app.js` должны находиться в одной папке. Для работы сайта не требуется npm, сборщик или отдельный сервер.

## Файлы проекта

- `index.html` — HTML-страница и подключение основных файлов.
- `style.css` — стили, адаптивная вёрстка и темы оформления.
- `app.js` — интерфейс, навигация, прохождение тестов и результаты.
- `questions.js` — список предметов, категории и массивы вопросов с вариантами ответов.
- `cloud.js` — логика локального кэша и необязательной облачной синхронизации.
- `README.md` — документация проекта.

## Данные и приватность

Лучшие результаты, выбранная тема и имя профиля сохраняются в локальном хранилище браузера. При использовании сайта без настройки облака данные остаются на текущем устройстве и в текущем браузере. Файл `cloud.js` содержит пустые значения `BIN_ID` и `API_KEY`; для фактической синхронизации требуется отдельно настроить совместимое хранилище и его доступы. Не публикуйте секретные ключи в открытом репозитории.

## Проверка количества вопросов

В `questions.js` для каждого теста указан ожидаемый размер `expected: 50`. Встроенная проверка выводит предупреждение в консоль, если фактическое количество вопросов в тесте отличается от ожидаемого.

Текущая структура: **81 тест × 50 вопросов = 4050 вопросов**, распределённых по 9 основным категориям.
