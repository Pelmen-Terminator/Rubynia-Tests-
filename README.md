# 🎓 Тесты

Интерактивные тесты для старшеклассников по 6 предметам: русский язык, математика, физика, химия, биология, история.

## Возможности

- 📚 6 предметов, по 40 вопросов в каждом (240 вопросов).
- 🎲 Перемешивание вопросов и вариантов ответов.
- 🏆 Оценка по 5-балльной шкале (90%+ — 5, 70%+ — 4, 50%+ — 3, иначе 2).
- 💾 Сохранение лучшей оценки в localStorage.
- ⏱️ Подсчёт времени прохождения.
- 📝 Разбор всех ответов после завершения.
- 🌓 Автоопределение тёмной темы + ручной переключатель.
- 📱 Адаптивная вёрстка, поддержка safe-area.
- 🔗 Кнопка «Поделиться результатом».
- 🧹 Без внешних зависимостей, без сборки.

## Файлы

- `index.html` — точка входа.
- `style.css` — стили.
- `questions.js` — база вопросов.
- `app.js` — логика приложения.
- `README.md` — этот файл.

## Запуск

Просто откройте `index.html` в браузере. Или разместите файлы на GitHub Pages.

## GitHub Pages

1. Загрузите все файлы в корень репозитория.
2. В настройках репозитория включите GitHub Pages (ветка `main`, папка `/root`).
3. Откройте `https://<username>.github.io/<repo>/`.
