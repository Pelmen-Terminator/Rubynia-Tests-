# 🎓 Тесты

Интерактивные тесты для старшеклассников. 6 предметов, **по 50 вопросов** в каждом (300 вопросов).

## Что нового в v1.1

- 📈 **50 вопросов** на каждый предмет.
- ☁️ **Облачное сохранение** результатов (jsonbin.io) + локальный fallback.
- 🎨 **Три темы**: светлая, бежевая, тёмная — с ручным выбором.
- 👤 Профиль пользователя с историей результатов.
- 📊 Просмотр всех прошлых попыток (оценка, %, дата).
- 🔗 Кнопка «Поделиться результатом».
- ⏱️ Подсчёт времени прохождения.
- 🎲 Перемешивание вопросов и ответов.
- 📝 Разбор ответов после завершения.

## Файлы

- `index.html` — точка входа.
- `style.css` — стили и три темы.
- `questions.js` — база вопросов (300 шт.).
- `cloud.js` — облачное хранилище.
- `app.js` — логика приложения.
- `README.md` — этот файл.

## Запуск

Откройте `index.html` в браузере. Всё работает без сборки и зависимостей.

## Настройка облака (опционально)

1. Зарегистрируйтесь на [jsonbin.io](https://jsonbin.io).
2. Создайте новый bin (пустой JSON `{}`).
3. Скопируйте **Bin ID** и **X-Master-Key**.
4. Откройте `cloud.js` и впишите их в `CONFIG`:

```js
const CONFIG = {
  BIN_ID: "ваш_bin_id",
  API_KEY: "ваш_x_master_key",
  BASE: "https://api.jsonbin.io/v3/b"
};
